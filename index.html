File: Adset_tagging_for_claude.xlsx. Columns: Adset · Script · Platform · Canvas · Adset Tag. Adset name must match QuickSight exactly (full pipe-separated string). Add new rows for new adsets. Leave Adset Tag blank if no specific tag. Do not rename or reorder columns.
Growth Bank Auto from CSV Derived from QuickSight CSV — no separate upload needed

Note on maturity cutoffs: D3 mature = install date ≤ May 16 · D7 mature = install date ≤ May 12. These update every time the tool is rebuilt with new data. Charts show solid lines for mature dates, dotted for immature. Card metrics show mature number in bold with immature in grey below.
